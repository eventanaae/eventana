# Eventana cloud library (`raw/library/`)

Durable, cloud-hosted copy of every **non-sensitive** Eventana asset, so the team
never depends on the office laptop (owner rule, 28 Nov 2026).

## What's here
| Folder | Contents |
|---|---|
| `brand/` | Logo, favicon, brand marks |
| `themes/` | Theme & backdrop references (catalogues, photos) |
| `designs/` | Design files / mockups |
| `photos-videos/` | Event photos & videos |
| `marketing/` | Ads, stories, campaigns, reels, social assets |
| `suppliers-prices/` | Supplier price lists & quotations (e.g. Kunming flowers) |
| `collateral/` | Catalogue, corporate profile, letterheads, party decks |

## What is deliberately **excluded** (stays on the laptop only)
Passports, Emirates IDs, company ID card, trade licence, contracts, job offers /
work permits, invoices, VAT declarations, statements of account (SOA), QuickBooks /
finance exports, and app source-code archives. These are **never** copied to the cloud.

_Built 28 Nov 2026 from the master folder `OneDrive/Eventana`. 430 files._
